PRsquad: Supervised Agentic Workflow

A 7-stage supervised multi-agent engineering workflow built natively for the GitHub Copilot App. Four deterministic mechanisms enforce safety and governance: Triage intercepts issues in <2s without burning LLM tokens; the Scope Gate physically blocks the Developer agent from starting until a maintainer signs approval.lock; the Write-Scope Barrier rejects out-of-scope mutations; and the Bounded Repair Loop hard-caps Developer↔QA fix iterations at 3 attempts. Cross-file symbol contracts are verified with a zero-token AST sweep before human merge review.

Enterprise Governance & Efficiency Mechanisms

Bounded Retry Ceilings (No Runaway Loops)

The Developer↔QA repair loop is hard-capped at 3 attempts. A 4th consecutive failure does not spend further LLM tokens — the pipeline pauses and notifies the maintainer. This eliminates the catastrophic multi-agent token bleed common in unconstrained loops.

Deterministic Scope Lock (approval.lock) & Approval Integrity Binding

Unlike prompt-based suggestions that models routinely bypass, the Scope Gate is enforced by a physical PreToolUse hook (hook-verify-gate.mjs). The Developer agent process is physically aborted at the operating system level unless a verified approval.lock authorized by a maintainer exists on disk, cryptographically bound to the canonical Architect plan hash (planHash).

Zero-Token Deterministic Symbol & Reference Sweep

Cross-file symbol impact is mapped deterministically using symbol extraction and repository reference sweeping (ast-symbol-sweep.ts), not an expensive LLM subagent. The sweep analyzes exported symbols and repository references in milliseconds with 0 LLM tokens, surfacing warnings directly to the Reviewer.

Semantic Instruction Slicing & Proximity Skills

Instead of dumping a monolithic repository instruction file into every agent prompt, PRsquad dynamically extracts only the sections relevant to the active specialist's role. Combined with directory-proximity skills (.prsquad/skills/), this reduces prompt token burn by 60% to 80%.
